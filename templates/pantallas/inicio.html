MAPIFY

    La propuesta es dotar de un sistema que permita la visualización de las rutas más óptimas hacia los bloques del Campus Universitario - Sector Argelia, este aporte ayudará a que el alumnado se incentive a realizar este tipo de proyectos tecnológicos, o a su vez puedan mejorar este sistema propuesto.


    Una de las razones principales para el desarrollo de esta aplicación es que consta como un requisito fundamental para la aprobación del cuarto ciclo correspondiente a la carrera de Computación, periodo académico Abril - Septiembre 2023. Además, se pretende proporcionar una herramienta confiable a la comunidad Universitaria con la cual puedan ser capaces de movilizarse e identificar las diferentes infraestructuras que existen dentro del Campus Universitario.


    Lo que se pretende lograr con el desarrollo e implementación de la aplicación, es promover una experiencia positiva para la comunidad universitaria que se traslada entre los distintos bloques del Campus Universitario - Sector Argelia. Al contar con la información adecuada y precisa, los estudiantes podrán ubicarse fácilmente dentro del campus universitario.

MAPIFY

    Para el desarrollo de Mapify, se empleó el entorno de desarrollo integrado (IDE) PyCharm, diseñado específicamente para la programación en el lenguaje Python. PyCharm ofrece una serie de características que agilizan el proceso de desarrollo de aplicaciones, entre las cuales destaca la depuración de código, una herramienta fundamental para identificar y corregir errores de manera eficiente.


    Para el cálculo de la ruta más óptima en Mapify, se tomó la decisión de emplear el algoritmo de Dijkstra, el cual fue adaptado y modificado para proporcionar la ruta desde un punto de origen específico hasta el punto de destino seleccionado.


    Dentro del IDE PyCharm, encontramos el framework Django, que simplifica la creación de la estructura de proyectos web mediante el uso de un conjunto de plantillas predefinidas.


    Además, se hizo uso de la tecnología Bootstrap, la cual proporciona un conjunto de herramientas, estilos predefinidos y componentes de interfaz de usuario que facilitan la creación de sitios web y aplicaciones web atractivas y responsivas
